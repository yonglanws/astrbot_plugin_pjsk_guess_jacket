# 猜曲绘排行榜未绑定 QQ 状态标签设计

## 目标

将未绑定的 QQ 官方机器人账号从“直接拼接在用户名左侧”的显示方式，调整为排行榜玩家栏中的独立状态标签，让用户名本身保持干净，同时保留清晰的未绑定提示。

## 已确认的视觉方案

- 仅对排行榜数据中的未绑定官方账号绘制标签，标签文字为“未绑定QQ”。
- 标签使用紧凑的灰色圆角背景和浅色文字，放在玩家名称左侧、同一行显示。
- 用户名仍使用现有的自定义名称优先和黑名单显示规则，不把标签拼进用户名字符串。
- 普通 QQ 账号和已经绑定的官方账号不显示该标签。
- 玩家 ID 行继续显示原始用户名和账号 ID，便于识别官方 QID。

## 实现范围

- 只调整 ImageGenerator.create_ranking_image 的玩家栏布局。
- 不修改 SQLite 表结构、绑定关系、积分计算和排行榜排序。
- 未带第 7 个未绑定标记字段的旧测试行继续按普通账号渲染，保持兼容。
- 标签出现后，用户名可用宽度按标签实际宽度动态减少，仍使用现有省略号截断规则。

## 验证标准

- 未绑定行的渲染文本中，“未绑定QQ”和用户名是两个独立绘制对象，而不是“未绑定QQ 用户名”一个字符串。
- 普通账号的用户名绘制位置和内容不变。
- 排行榜图片尺寸、列位置、分数、正确率、次数和 ID 行不变。
- 单元测试和本地排行榜渲染均通过。
